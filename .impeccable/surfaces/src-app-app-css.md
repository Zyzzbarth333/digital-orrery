# Orrery console (the main screen)

Scope: the panels around the 3D sky (header band, body rail, data plate, scene markers). Mode: Operate.
Audience and job: the engineer reads exact values and drives time and focus (keyboard included); a portfolio visitor grasps "real solar system, real numbers" in seconds, on a phone too.
Constraints: Australian English; original retro-futurist feel in the NASA-punk lineage of real NASA hardware (the user likes Starfield's vibe; take nothing from that game's own interface, logo, stripe or fonts); standard web controls; works at 390 px.

## Direction contract

seed: none (pinned; the user chose world A of three rendered mockups)

THESIS: 70s flight hardware whose every number shows where it came from. Refuses the dark glass dashboard of space-viz apps.

OWN-WORLD: Beige sheet-metal panels with screw heads, dark ink, orange-red engraved Michroma capitals, recessed black readout windows with amber B612 numerals, square lamps, an orange RUN key, black nomenclature strips, Shuttle-style panel codes, the sky in a dark bezel. Caution hatching only for warnings.

STORY: The sky is the viewport of a spacecraft console; the clock and rate are its instruments; the plate reads out the target.

FIRST VIEWPORT: The header band with the running UTC clock lit amber in its window and the RUN key lit, the sky in its bezel, the data plate's provenance tags.

SIGNATURE: The provenance column: each readout's source tag (AE, DE442, the satellite kernel, IAU, NSSDCA), dashed for derived values.

RISK: Beige panels around a black sky are high contrast; keep panels quiet (no extra ornament) so the sky leads.
