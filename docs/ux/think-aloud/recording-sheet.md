## Single Ease Question (SEQ)

Asked straight after each task: *"Overall, how difficult or easy was this
task to complete?"* 1 = very difficult, 7 = very easy. A score under 5 is
below the usual average for tasks and worth a look, whatever the success.

## System Usability Scale (SUS)

Given at the end, filled in by the participant alone. *For each statement,
circle one number: 1 = strongly disagree, 5 = strongly agree. Answer every
one; if unsure, circle 3.*

| # | Statement | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 1 | I think that I would like to use this system frequently. | | | | | |
| 2 | I found the system unnecessarily complex. | | | | | |
| 3 | I thought the system was easy to use. | | | | | |
| 4 | I think that I would need the support of a technical person to be able to use this system. | | | | | |
| 5 | I found the various functions in this system were well integrated. | | | | | |
| 6 | I thought there was too much inconsistency in this system. | | | | | |
| 7 | I would imagine that most people would learn to use this system very quickly. | | | | | |
| 8 | I found the system very cumbersome to use. | | | | | |
| 9 | I felt very confident using the system. | | | | | |
| 10 | I needed to learn a lot of things before I could get going with this system. | | | | | |

SUS by John Brooke (1986, published 1996), free to use with this
acknowledgement.

**Scoring** (for the facilitator, after the session): for the odd items
(1, 3, 5, 7, 9) score = answer − 1; for the even items (2, 4, 6, 8, 10)
score = 5 − answer. Add the ten scores and multiply by 2.5, giving 0–100.
About 68 is the usual average; above 80 is good.
